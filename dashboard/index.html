Methodology

How value is modeled

Implied value uses only total value locked (TVL), seven-day growth, age with no token, category tier and chain diversity. The same rules apply to every protocol, regardless of name.

Start with TVL times its category multiple. Scale that base by maturity times the growth factor, plus the bonus for extra chains, less the discount for newer protocols. Round and bound the result.

The pre-token board lists protocols with the status “records no token” in the snapshot. Protocols whose token already trades appear in the separate live-token view, ordered by recorded market cap.
